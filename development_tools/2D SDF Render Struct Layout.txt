///////////////////////////////////////////////////////////////////////
///////////////////////////////////////////////////////////////////////

vec4 i_data0     : TEXCOORD7;
-----------------------------

x: X Position COMBINED WITH Y Position (V)
y: X Size COMBINED WITH Y Size (V)
z: Point Count COMBINED WITH Gradient Type (See below) (F)
w: Rotation (Rotation in plane only) (V)

vec4 i_data1     : TEXCOORD6;
-----------------------------

x: Color Start Index (F) (as ints, divide in shader)
y: Shape Type COMBINED WITH Width (See below) (F)
z: X Texture Texture Coordinate Start COMBINED WITH Y Texture Texture Coordinate End (F) (as ints, divide in shader)
w: X Texture Texture Size (width) COMBINED WITH Y Texture Texture Size (height) (F) (as ints, divide in shader)

vec4 i_data2     : TEXCOORD5;
-----------------------------

x: UNUSED
y: UNUSED
z: UNUSED
w: UNUSED

Shape Types
===========

0: Rectangle/Square
1: Rounded Rectangle/Square
2: Circle / Ellipse (not differentiated, depends on sizes for scale)
3: Arc
4: Line
5: Text (for text rendering!)

Polygon rendering not supported here
